### Key Features

- Full support for Hotline 1.5 protocol specifications.
- Public and private chat with user list.
- Resumable file transfers (uploads and downloads).
- Server news and message board (bbcode/text rendering).
- Modern, clean interface.
- Cross-platform support (Windows, macOS, Linux).

## History

Development on Hotline Connect Client began in late 2024 by \[Creator Name\]. The primary motivation was the lack of actively maintained, modern clients for the Hotline protocol, especially on platforms like macOS and Linux.

The client is built using \[C# and .NET MAUI / C++ and Qt / etc.\] which allows a single codebase to target multiple operating systems. The first public beta (v0.9.0) was released in April 2025, with the 1.0.0 stable release following in October 2025. The project is \[open-source/closed-source\] and development is ongoing.
