## Server Software

<u>**Official**</u>

- Hotline Connect Server - v1.2.3 ([Mac Classic 68k](http://preterhuman.net/download/HotlineServer1.2.368K.sit.hqx), [Mac Classic PPC](http://preterhuman.net/download/Hotline_Server-1.2.3_PPC.hqx), [Windows](http://preterhuman.net/download/Hotline_Server-1.2.3_win.zip))
- Hotline FTP Server ([Mac Classic PPC](http://preterhuman.net/download/HotlineFTPServ1.0PPC.sit.hqx), [Windows](http://preterhuman.net/download/FTPServPC.zip))

<u>**Derivatives**</u>

- GLoarbLine Server (Mac OS X PPC and Carbon, Windows)

<u>**Third party**</u>

- [Janus](http://agora.vespernet.net) - Multiplatform command line server
- Javaline Server (Multiplatform Mac, WIndows, Unix) made in Java can be downloaded from the UberSoft hotline server at hotline.ubersoft.org (requires JRE 8+) the link is to the source code and compiled java bin since the Source Code to Javaline was released March 2021 if anybody wants to take over it make sure to head over to the official Pitbull Pro development server so you can add compatibility and what not with Pitbull Pro (if you so wish to)
- [mhxd (Unix) (0.4.10 tarball)](http://preterhuman.net/download/mhxd-0.4.10.tar.bz2) [(0.4.11 repo)](https://github.com/Schala/mhxd)
- [Mobius](http://github.com/jhalter/mobius) - Multiplatform command line server and client implemented in Golang
- [phxd (Python)](https://bitbucket.org/avaraline/phxd) - Python 2.x compatible ONLY - Docker Supported
- [phxd (Unix)](http://code.google.com/p/phxd/)
- [Pitbull Server](http://ubersoft.org/pitbullserver/) - (Windows)
- [rhxd](https://github.com/DaCodeChick/rhxd) Multiplatform (Mac, Windows, Unix) server and tracker written in Rust for safe concurrency and memory safety using Tokio for asynchronous networking. Aims to support as much of the official and third party extensions to Hotline as possible. Very early development. NOTE: Vibe coded (AI used in development)
