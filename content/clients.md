Hotline clients allow for a connection between the user and the server. They essentially provide the user with an experience, allowing them to view files and folders on the server, read the news BBS, chat and communicate with the community.

Because Hotline was originally intended as a chatting P2P client, most people focused on one or the other. Hotline is a good place to find files, however it also houses a fairly large chat community, and allows you to communicate with other users. Since Hotline came prior to Facebook, BitTorrent, and Gnutella, it truely was remarkable for its time. It still exists, and you can feel free to download one of the clients below and see for yourself. :)

## Currently under development

Many Hotline users have decided over time to develop their own clients, serving particular purposes that are not available in other clients or featuring a personalized user interface.

These are the clients that are being actively developed by the Hotline community:

[Decline](https://github.com/dubsdotla/decline/) - Obj-C for modern macOS with / commands to handle a lot. This is early stages but looking promising!

[Hermes](http://agora.vespernet.net/) - Another modern Hotline client in the early stages of development.

[Hotline (SwiftUI)](https://github.com/mierau/hotline/releases/) - Modern Hotline client built in SwiftUI, for macOS 14.2.1 and up. [<small>Readme</small>](https://github.com/mierau/hotline/blob/main/README.md) can be found on Github.

[Hotline Navigator](https://github.com/fuzzywalrus/hotline) - Works with OSX, Windows, and Linux. Pretty nice based on the Swift version of Hotline for OSX.

[HotStuff](https://macintoshgarden.org/apps/hotstuff) - Hotline client for System Software 7.1, up to Mac OS X 10.5 "Leopard". (active development from System7Today community Leader Knezzen)

[Mobius](https://github.com/jhalter/mobius/releases), open source, written in Go! this offers a command line client that works in all OS (Guides for Mac OS using Homebrew or Linux are present in [<small>Readme</small>](https://github.com/jhalter/mobius/blob/335f5eb5851db549f7654852296a48b2137f248f/README.md))

[Obsession](https://github.com/tjohnman/Obsession/releases), open source and written in Qt, for Windows, Linux and macOS users. Find the [<small>Readme</small>](https://github.com/tjohnman/Obsession/blob/qt4/README.md) for support of macOS and Linux.
