### Key Features

- Full support for Hotline 1.5 protocol specifications.
- Public and private chat with user list.
- Resumable file transfers (uploads and downloads).
- Server news and message board rendering.
- Native look and feel for macOS Classic.

## History

Development on HotStuff! began in 2023 by Theo Knez. The client is built for classic macOS and supports both FAT (68k/PPC) and CARBON (OS X) binaries. It has seen steady development, with the latest version released on October 13, 2025.
